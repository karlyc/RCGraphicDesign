The configurator's workhorse: one tile per paper, size, coating or turnaround option. Stack 2-5 in a column or grid.

```jsx
<OptionTile title="16pt matte" meta="Uncoated back" priceNote="+$14" selected swatch="#EFEDE7" onClick={…} />
```

Selected state = magenta border + 2px ring + magenta-50 fill.
